# 🏋️ GearUp Frontend

A modern sports gear rental platform built with **Next.js 16**, **TypeScript**, and **React Query**. GearUp allows customers to rent sports equipment, providers to manage their inventory, and administrators to control the entire platform through dedicated dashboards.
